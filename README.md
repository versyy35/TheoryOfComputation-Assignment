# CSE6344 Assignment 1 - NFA, DFA, Regular Expressions

## Assignment Goal
Create a single DFA that accepts all 20 given strings.

## How It Was Done
1. **Split work**: Each member took 5 strings
2. **Individual work**: Each member made regex → NFA → DFA for their strings
3. **Combined**: All 4 DFAs were merged into one final DFA
4. **Tested**: Verified the final DFA accepts all 20 strings
