---------------------------------------------------------------------------------------
                        WHAT TO DO IN THIS PART OF THE ASSIGNMENT
---------------------------------------------------------------------------------------


✅ STEP 1: WRITE REGULAR EXPRESSION
    1. Open regex.txt
    2. Write ONE regular expression that matches ALL your 5 strings
        Example:
        Given: *n*, *x*, *g*, *2*, nx*
        Regex: (\*n\*|\*x\*|\*g\*|\*2\*|nx\*)
    3. Save file

✅ STEP 2: CREATE NFA IN JFLAP

    1. Open JFLAP
    2. Click "Regular Expression"
    3. Copy-paste your regex from regex.txt
    4. Click "Do It" - JFLAP builds NFA automatically
    5. Save as nfa.jff in your member folder

✅ STEP 3: CONVERT NFA TO DFA
    1. Open your nfa.jff in JFLAP
    2. Go to: Convert → Convert NFA to DFA
    3. JFLAP opens new window with DFA
    4. (Optional) Convert → Minimize DFA
    5. Save as dfa.jff

✅ STEP 4: TEST YOUR DFA
    1. Open dfa.jff in JFLAP
    2. Go to: Input → Multiple Run
    3. Enter ACCEPT strings (your 5 strings, one per line)
    4. Enter REJECT strings (5 strings NOT in your set)
    5. Run tests
    6. Record results in tests.txt
        Example:
        ------------------------------------------------
        | ACCEPTED STRING      |      REJECTED STRING. |
        |       aaaa           |          aaab         |         
        |      abababa         |     abababababbbbbb   |
        ------------------------------------------------
✅ STEP 5: VERIFY & PUSH
    1. Check all files exist:
       - regex.txt
       - nfa.jff
       - dfa.jff
       - tests.txt
    2. Open GitHub Desktop / terminal
    3. Commit to GitHub
    4. Push to repository

📌 TROUBLESHOOTING
    1. Regex not working? Test at: https://regex101.com/
    2. JFLAP error? Check for special characters (escape * with *)
    3. DFA too big? That's OK - JFLAP handles it
    4. Not sure about reject strings? Ask your group

🎯 REMEMBER
    1. You create ONLY ONE of each: 1 regex, 1 NFA, 1 DFA
    2. Test with YOUR strings only (5 accepts, 5 rejects)
    3. Save ALL files in YOUR member folder
    4. Do NOT modify other members' work
